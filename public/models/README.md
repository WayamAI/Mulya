# Mūlya 3D models

## Real CAD parts (`parts/`)

B-rep solids of the three demo parts, modelled with the OpenCascade kernel
(`replicad` + `replicad-opencascadejs`, WASM) by `npm run cad`
(`scripts/build-cad.mjs`). Don't edit by hand; change the script and re-run.
All files share one frame: **millimetres, +Y up, origin at the bounding-box centre**.

| Variant | Part | Process / material | Frame (X × Y × Z mm) |
|---|---|---|---|
| `bearing` | DTV-HSG-0431 Bearing Housing Rev B | Sand cast EN-GJL-250 (GG25) | 248 × 186 × 94, bore axis Z |
| `bracket` | DTV-BRK-0117 Cab Mount Bracket Rev B | Stamped HC340LA, t 2.5 | 186 × 64 × 92, bend lines along Z |
| `cover` | DTV-CVR-0288 Gearbox End Cover Rev C | HPDC EN AC-43000 (AlSi10Mg) | 196 × 196 × 48, axis Z (outside face +Z) |

Per variant:

| File | What it is |
|---|---|
| `DTV-…_Rev?.step` | STEP AP214 (AUTOMOTIVE_DESIGN) solid under the file name the app shows, with the part's header, PRODUCT record, revision and design notes (DESCRIPTIVE_REPRESENTATION_ITEMs, incl. MEASURED_* values). Also the sample file for the New Estimate upload. |
| `<variant>.stl` | Binary STL of the same tessellation |
| `<variant>.glb` | Binary glTF for download: one mesh named `body` (indexed, vertex normals, PBR material) |
| `<variant>.edges.json` | Sharp CAD feature edges (faces meeting at > 18°) as a flat array of line-segment endpoints `[x1,y1,z1, x2,y2,z2, …]`, same frame as the GLB |
| `<variant>.web.glb` | What the viewer loads: the mesh plus the edges as a `LINES` primitive, quantized and meshopt-compressed (`npm run models:web`) |
| `manifest.json` | Per variant: part number, name, revision, process, material, density, file names, bbox (mm), volume, surface area, mass, face/edge/triangle counts |

## Production tools

Binary glTF (`.glb`) of the tool that makes each sample part, generated by `npm run models`
(`scripts/export-models.mjs`) from the same builder the MouldViewer uses
(`src/lib/models/mould-geometry.mjs`). Units are scene units (not mm). Materials are PBR
metallic-roughness and match the viewer colours.

Each tool is exported twice: at the viewer's default 70 % open, and closed (`-closed`).
The moving half is the node `upper-half` (two-plate tools) or `upper-die`
(progressive); raise it by `fraction × 2.3` along Y to open the tool.

| File | What it is |
|---|---|
| `mould-pattern-bearing.glb` / `-closed` | Sand-casting pattern plate (two halves, guide pillars, sprue, runner and gates) with two core-box stacks, holding the bearing housing |
| `mould-progressive-bracket.glb` / `-closed` | Progressive stamping die set (upper shoe, punch plate, piercing and forming punches, lower shoe, die block, four guide posts) over the strip, with the bracket at the exit |
| `mould-die-cover.glb` / `-closed` | High-pressure die-casting die (steel halves, cavity inserts, guide pillars, sprue, runner) with two side slides and ejectors, holding the cover |
